# Images & Assets Directory

Place your logos, institutional insignias, branding assets, and examination diagrams here.

### Supported formats
- PNG (`.png`)
- SVG (`.svg`)
- JPEG (`.jpg` / `.jpeg`)
- WebP (`.webp`)

### Usage in React Components
You can import images directly in your components:
```tsx
import logo from '../images/talent_iq_logo.svg';
// or place in public/ and reference via absolute path '/images/logo.png'
```
